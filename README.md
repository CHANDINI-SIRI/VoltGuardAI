# ⚡ VoltGuard — AI Electricity Leak, Theft & Subsidy Protection System

Built with **FastAPI + Tailwind CSS + Plotly.js + Scikit-Learn + Tesseract OCR** (replacing Streamlit for a true production SaaS experience).

## Quick Start (3 Commands)
```bash
pip install -r requirements.txt
uvicorn app:app --reload
```
Open **http://127.0.0.1:8000** in your browser.
